# 얼굴 UV를 한 덩어리로 유지하는 옵션

| 항목 | 값 |
| --- | --- |
| 報告の種類 / Type | 改善案 / Suggestion |
| キットの版 / Kit version | 1.0.4 |
| OS・ブラウザ / OS and browser | Windows 10 / Chrome |
| エージェント・モデル・工程 / Agent, model and stage | Codex(모델 기입) / 재텍스처·UV 단계 |

## 行った操作・提案 / Steps or proposal
머리 모델을 Smart UV로 펼친 뒤 재텍스처했다. 제안: 얼굴(피부 앞면) 영역은 UV를 한 섬으로 유지하는 지시나 옵션을 두면 좋겠다.

## 期待した結果 / Expected result
눈·입 영역이 텍스처의 한 구역에 모여 있어 표정 텍스처를 그릴 수 있다.

## 実際の結果 / Actual result
얼굴이 여러 섬으로 쪼개져 눈/입 영역이 텍스처 전체에 흩어진다. 표정 작업이 사실상 어렵다.
