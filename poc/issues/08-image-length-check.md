# 이미지 단계에서 원본 대비 길이·볼륨 검수

| 항목 | 값 |
| --- | --- |
| 報告の種類 / Type | 改善案 / Suggestion |
| キットの版 / Kit version | 1.0.4 |
| OS・ブラウザ / OS and browser | Windows 10 / Chrome |
| エージェント・モデル・工程 / Agent, model and stage | Codex(모델 기입) / 부위 이미지 확인 |

## 行った操作・提案 / Steps or proposal
머리 4방향 이미지를 확인 지점에서 통과시켰다. 제안: 확인 화면이나 Skills 지시에 원본 일러스트와 머리 길이·후드 볼륨·색 비율을 비교하는 검수 항목을 둔다.

## 期待した結果 / Expected result
3D 후보의 머리 길이와 볼륨이 원본과 비슷하다.

## 実際の結果 / Actual result
뒤/옆 이미지가 가슴 높이에서 끝나 3D 머리가 원본보다 짧게 나왔다. 후드는 반대로 너무 커서 애니메이션에서 팔·머리카락이 통과했다.

## 첨부

- 머리 길이 비교 렌더는 원본 일러스트가 함께 보여야 해서 아직 넣지 않았다.
